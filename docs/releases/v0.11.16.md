# Leaflight v0.11.16 — Long EPUB import

- Local TXT/EPUB imports now support up to 5,000 chapters/parts, independently of the 100-chapter AI-generation and community-sharing contracts.
- Ordinary HTML/XHTML doctypes and common named entities are accepted. Custom entities are rejected and external DTDs are never fetched.
- Archive inflation runs in a worker; chapter parsing yields between batches. Long chapters are split at paragraph/word boundaries, preserving text and order.
- Book storage, bookmarks, restart and JSON backup validation retain long imported books. Backup file limit is 128 MiB; import errors distinguish structure, encryption, encoding and resource limits.
- Android Reader 0.3.0-preview.5 shares the parser/storage rules. Web previews report storage quota failures instead of claiming a long book was saved.

[Usage and limits](../long-book-import.md). Final installer/source identities and actual verification results are in Release attachments. Mac is Apple Silicon/ad-hoc signed, without Developer ID or notarization; default Gatekeeper launch may be blocked. Manual updates only. Physical Pad, minimum OS and clean-machine verification are not implied. No model calls are needed for this fix or its import tests.
