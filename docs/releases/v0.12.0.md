# Leaflight v0.12.0 — Full window, Windows package, iOS reader project

- Mac and Windows can show the reader, editor, or review across the whole window. The sidebar, page header, and system menu bar hide. Inbox and Exit full window stay available. Esc restores the previous layout and keeps the current reading text. The application Edit menu remains so copy and paste shortcuts still work.
- Desktop version is 0.12.0. The release includes an unsigned 64-bit NSIS installer, `Leaflight-0.12.0-win-x64-setup.exe`.
- iOS Reader 0.1.0-preview.1 is a new project with the Android reader's scope. The attached IPA is unsigned and is not a device installer until an Apple Development identity signs it. Android remains 0.3.0-preview.5.
