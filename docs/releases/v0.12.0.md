# Leaflight v0.12.0 — Full window and Windows package

- Current source and the web preview can show the reader, editor, or review across the whole window. The sidebar, page header, and system menu bar hide. Inbox and Exit appear briefly at the top right after entering full window or tapping the page, in landscape and portrait, then hide. They are plain text, without a filled button. Esc restores the previous layout and keeps the current reading text. The application Edit menu remains so copy and paste shortcuts still work.
- Desktop version is 0.12.0. The release includes an unsigned 64-bit NSIS installer, `Leaflight-0.12.0-win-x64-setup.exe`.
- The unsigned iOS archive was removed from this release and from the repository. iPadOS will not install it. iPhone and iPad use the [web preview](https://jayson-sheyue.github.io/Leaflight/).

The Mac DMG passed `hdiutil verify`. The app inside is version 0.12.0, bundle id `local.novelreading.app`, ad-hoc signed, with sealed resources, and without notarization. `spctl --assess --type execute` rejected it. On this Mac the packaged app passed the full-window reading, writing, and review checks, including native fullscreen and restoring the menu bar on exit. It was not copied over `/Applications`.

The Windows file is an unsigned NSIS installer. It was not installed or launched on Windows. The DMG and Windows installer attached to this release were built before the standing full-window controls were removed. The web preview picks up that change when GitHub Pages finishes deploying the later commit.

The original release also attached `Leaflight-Reader-0.1.0-preview.1-ios-unsigned.ipa`. It was unsigned, was not launched on a simulator or device, and could not be installed. That file has been deleted.
