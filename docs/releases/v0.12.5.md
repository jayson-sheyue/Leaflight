# Leaflight v0.12.5 — Complete revisions include expression polish

- Fixed conflicting writing-review instructions that restricted the complete reference to minimal grammar corrections while leaving expression polish out.
- New complete references incorporate corrections and stylistic suggestions from all four dimensions and the expression-polish section, using coherent natural wording rather than mechanically replacing overlapping passages.
- References improve collocations, literal translations, repetition, transitions and sentence flow. When feedback identifies an exceeded exercise length range, the reference is shortened accordingly, retaining core meaning and facts without inventing missing content.
- The model is instructed to cross-check the reference against its review before returning it. This is prompt guidance, not a deterministic guarantee of writing quality.
- The original draft and old reviews remain unchanged. Re-submit an existing draft for a new review; save the reference separately when desired.
- Mac and Windows share this writing-review fix. Android remains 0.3.0-preview.9; Android and the static web preview do not offer AI writing review.
