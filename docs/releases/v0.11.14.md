# Leaflight v0.11.14 — 长篇分享包与按需借阅

- 分享改为保存 ZIP 后在 GitHub 投稿页上传附件，长篇不再塞进 Issue 正文；收录成功或失败由机器人回复在原投稿下。
- 共享书池同步仅下载目录和试读，加入书架时再下载并验证全文，保存后可离线阅读。
- 兼容旧 JSON 分享文件与 Issue 正文投稿；支持直接导入 ZIP。长篇 Token 直传在发送前提示改用分享包。
- 全局消息盒子保留分享包和借阅任务结果；修复导入分享文件后的返回数据，并保留断网时的原有目录与同步时间。
- Android Reader 0.3.0-preview.3 同步 ZIP 分享、目录、按需借阅、校验与消息记录，版本独立。

使用说明：[共享书池](../community-pool.md)。当前每书最多 100 章、每章少于 150,000 字符，ZIP 25 MiB / 解压 JSON 30 MiB；不会裁剪正文。

## 安装限制

macOS Apple Silicon，完整 ad-hoc 资源签名；**没有 Apple Developer ID 签名和 Apple 公证**，Gatekeeper 不会默认放行。首次安装仍可能被拦截，详见 [macOS 安装说明](../macos-installation.md)。不关闭系统安全机制。当前从 Release 手动下载更新，尚未具备自动安装更新能力。

对应产物：`Leaflight-0.11.14-arm64.dmg`。新版本使用独立 tag，不覆盖旧包。验证范围、源码提交及 SHA-256 见 Release 附件。

## 已执行验证

- 70 项 Mac / 共享模块单元测试、10 项 Android 单元测试及两端 TypeScript / Vite 构建。
- 桌面实际进程验证 24 章 ZIP 导出、目录仅一次请求、借阅才请求正文、校验、消息记录和重启后离线阅读。
- Android 浏览器验证 24 章 ZIP 导出／导入、按需下载与 360px / 800px 布局。
- Android 16 ARM64 专用模拟器验证公开旧 APK 到新版覆盖升级、数据与测试密钥保留，并验证系统 ZIP 保存／取消、Java ZIP 与共享解析器互通、24 章完整性及消息重启保留。

网络时序回归使用受控响应；另已完成下面的真实线上验收。不包含实体 Pad、最低系统版本实机或付费 Gemini 调用。
