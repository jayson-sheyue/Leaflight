# Leaflight Reader · Android 0.2.1-preview.1

2026-10-30 · Android 10（API 29）及以上 · 独立预览项目

## 功能

- 导入 Mac JSON 备份、本机阅读备份、UTF-8 TXT 与未加密 EPUB；英文、日文和假名注音离线阅读。
- 10 套主题、4 类设备字体、字号、行距、正文宽度、分页/滚动、翻页效果、书签、进度及专注模式。
- 三种界面语言，针对手机及 Pad 横竖屏调整布局。
- 用户配置 Gemini 模型与密钥，可生成一篇完整的英日独立短篇；生成时继续阅读，状态与结果显示在全局消息盒子中。生成需要联网且可能产生 API 费用。
- 密钥通过 Android Keystore 加密保存，不包含在 JSON 备份中；应用或进程结束时未完成任务标记中断，不会自动重试。
- 修正动画副本继承隐藏状态造成的下一页空白、结束时突然出现文字的问题。

## 验证与限制

本版浏览器回归覆盖动画期间正文可见、横竖屏文字位置、书签、字体、主题、文件导入导出、日语注音和错误文件保护；4 项存储测试通过。生成流程使用模拟响应验证，未调用真实付费 Gemini API。

上一预览版曾通过 Android 16 ARM64 专用模拟器的系统文件导入/导出、覆盖升级、密钥库和阅读验证。本版模拟器因开发机可用磁盘空间不足未能启动；本版 APK 与实体 Pad、最低 Android 版本未完成实机复验，故作为预览发布。

这是本机调试签名的 APK，尚未上架；没有自动更新。跨构建保留同一签名可覆盖安装；正式签名变更可能需要先导出备份、重新安装。版本清单声明的最低 Android 版本不等于已完成该版本实机验收。

暂不支持 Mac 的连续章节生成、写作评审、自动同步、PDF 或加密 EPUB。Android 阅读备份用于安卓版恢复，不能直接作为 Mac 全库备份导入。卸载应用前先导出备份。
