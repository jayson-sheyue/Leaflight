# Leaflight Reader 0.3.0-preview.5

VersionCode 8; corresponds to Mac v0.11.16. Local EPUB/TXT novels support up to 5,000 chapters/parts, with the same parser, ordinary XHTML doctype support, bounded background inflation, readable errors, and long-book backup/reading-state retention. AI series and the public pool remain limited to 100 chapters.

[Import limits and tests](../long-book-import.md) · [Android setup](../../android-reader/README.md). Same preview signing certificate; install over the previous version without uninstalling. This is a debug-signed preview, not a store release. Actual APK/emulator upgrade checks are documented in Release attachments. Physical Pad, minimum Android 10, and clean-machine testing remain unverified. Updates are manual; no OTA.
