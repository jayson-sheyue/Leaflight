# Leaflight v0.11.6

2026-10-27 · Apple Silicon macOS · 手动安装 DMG

## 新增与修复

- 阅读、写作编辑和 AI 评审区提供「放大」按钮。导航收为图标栏，其他面板收起；「恢复布局」或 Esc 返回。
- 放大与恢复保留草稿、选区和评审展开状态。阅读位置使用文字锚点，兼容旧进度；翻页、布局变化及重新打开作品时继续定位。
- 消息盒子在放大时覆盖显示，不挤压主面板。打开评审结果或定位原文时自动显示相应面板。Esc 优先关闭弹窗与消息盒子。
- 原文与完整修订参考稿支持整行点击、Enter 与空格展开，无需重新生成评审。
- 书签开关与取消使用同一匹配规则并按 ID 删除；支持旧书签、字号变化后的书签和同页重复记录，列表右侧「×」可直接删除。
- README 同步安装、设置和更新说明，修正未实现的词汇测验、考试评分及服务商兼容等描述。

v0.11.5 是本地开发构建，其修复包含在本版本中；没有单独的公开 Release。

## 验证与限制

本机已验证类型检查、构建、55 项单元测试，以及实际 DMG 中应用的面板放大、阅读位置保留、评审展开与书签取消。桌面测试使用隔离数据和受控响应，不调用真实 Gemini，也不修改个人书库。详细执行结果与旧版升级检查记录于 Release 的 `verification.json` 附件。

当前未做 Apple 开发者签名或公证；没有应用内安全自动更新。未完成干净机器、最低系统版本实机和真实 Gemini 服务验收，不承诺这些项目已通过。系统元数据声明最低 macOS 12.0，当前仅提供 arm64 包。

## 从旧版更新

1. 在系统设置导出全库备份，保留需要的草稿与评审。
2. 等待后台任务完成并退出 Leaflight。
3. 从本版本 Release 下载 DMG，将 Leaflight.app 替换到原安装位置。
4. 保留 `~/Library/Application Support/novel-reading/`，重新打开后检查书库和草稿。不要把替换应用与删除用户数据混为一谈。

SHA-256 不代替发布者签名。暂不支持应用内下载、安装、自动重启或自动回滚；安装受系统阻止时不要关闭系统整体安全保护。
