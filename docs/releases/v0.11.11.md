# Leaflight v0.11.11

2026-10-30 · Apple Silicon macOS · 手动安装 DMG

## 连续生成多章

打开作品，在章节目录下选择「连续生成多章」，填写章数或选择剩余全部章节，即可在后台准备后续内容；原有「生成下一章」仍可使用。

- 按故事顺序逐章请求，每章使用最新的摘要和连续性记忆；每章成功后立即归档，可继续阅读已有内容，在消息盒子查看进度并打开已保存章节。
- 支持停止生成。失败、停止或退出时，已保存的章节会保留；手动点击「继续未完成章节」只补齐原定范围内未完成的章节。重启不会自动发起付费请求。
- 每章一次 API 调用，费用由自己的 Gemini 账户承担；已发出的请求仍可能计费。本功能减少重复点击，不承诺缩短模型生成单章的时间。
- 同一作品的单章和多章任务共享占用检查，避免重复生成；多章任务沿用开始时的 Key 和已选模型，中途更改设置不混用。

## 试读引导

- 「调整设定」改为「修改要求，重新试读」：返回最初的创作要求并保留输入，修改后生成新的试读与大纲；不基于已生成的大纲做局部编辑。
- 设定说明、费用和停止说明放进折叠区，主要操作保持简短。中、英、日界面同步。
- 「同情节难度对照」仍是辅助选级的短场景试读，不生成整部小说的两个版本。
