# Leaflight v0.11.9

2026-10-30 · Apple Silicon macOS · 手动安装 DMG

## 本次更新

此版本包含 v0.11.7–v0.11.9 的本地更新；这些中间版本此前没有公开 Release。

- AI 写作评审增加独立的表达润色建议，提供原文、可选表达、理由及定位，原文不会被自动替换。
- 写作题库由 132 道扩充为 184 道英日原创练习，增加 IELTS/EJU 风格题、学段和日常场景；支持输入自备题目或写作目标。
- 96 道科学专项写作练习按物理、化学、生物、地球与宇宙的 24 个单元组织，每单元提供概念解释和证据推理；移除新题中的幻想故事要求，旧草稿与评审保留原题快照。
- 书架增加 UTF-8 TXT、未加密 EPUB 导入，支持文字章节和可识别的日语注音。导入产生新副本，不覆盖原书；不会把导入作品标成 AI 原创或宣称已测定语言等级。
- 同一源码提交新增独立 Android 阅读项目，包含英日单篇故事生成、离线阅读、主题、字体、翻页、书签、进度与文件导入。Android 安装包作为独立预览 Release 提供。

内置写作题均为原创训练材料，不是剑桥雅思原题或教材摘录。

## 已验证与限制

已执行 57 项 Mac 单元测试；隔离数据的打包版科学读写联动、客观题、参考笔记、受控 AI 评审、旧题快照、备份与重启测试通过。实际打包版也验证了 Leaflight 导出的 EPUB 与 UTF-8 TXT 再导入、损坏文件不影响书库及完整备份恢复。AI 测试使用模拟响应，未发起真实付费 API 调用。

本机已从安装目录中的 0.11.8 正常退出、保留旧应用并替换为 0.11.9，再启动新版；沿用原用户数据目录。此操作是手动安装验证，不是 OTA 验证，也不等同于干净机器验收。

Mac 包未经过 Apple 开发者签名或公证；没有应用内安全自动更新。最低系统版本声明为 macOS 12.0，仅提供 arm64；干净机器、最低版本实机和真实 Gemini 服务验收尚未完成。SHA-256 用于完整性校验，不代替开发者签名。

TXT/EPUB 文件上限 20 MB，EPUB 解压内容上限 8 MB；EPUB 不支持加密内容，不保证保留图片、原排版或所有复杂结构。单篇文件不包含原始书签、进度、写作资料和生成设定，完整迁移请使用 JSON 备份。

## 更新方式

先导出全库 JSON 备份，等待生成任务完成并退出应用，再用新版 DMG 替换应用。保留 `~/Library/Application Support/novel-reading/` 用户数据目录。
