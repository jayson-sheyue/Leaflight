# Leaflight Reader · Android 0.3.0-preview.1

2026-10-30 · Android 10（API 29）及以上 · 独立预览客户端

## 与 Mac 0.11.11 对应的连载创作

- 「生成故事」新增章节连载，选择语言、难度与题材，填写自己的想法；篇幅和总章节数收在更多选项中。保留原有独立短篇。
- 连载先生成试读与大纲，在生成消息中查看并确认加入书架。试读页的「修改要求，重新试读」返回最初的创作要求，保留输入，修改后生成新的试读与大纲；不编辑上一次生成的大纲。
- 新作品和「目录与书签」中可生成下一章或连续多章；可选章数或全部剩余章节。每章一次 API 请求，按顺序使用最新摘要与连续性记忆，每章成功后立即保存，生成期间可继续阅读。
- 生成消息提供进度、结果入口、停止与手动继续。失败、停止或系统结束进程时保留已保存章节；手动继续只补原定范围内剩余章节，不会自动重复付费请求。已经发出的请求仍可能计费。
- 任务使用开始时的模型和密钥快照；密钥快照仅保留在原生内存，密钥使用 Android Keystore 加密保存，任务记录和备份不包含密钥。
- 阅读进度和书签保存不会覆盖后台刚生成的新章节。完整 Mac 备份中的连载信息可以导入；早期安卓已导入的作品可重新导入完整 Mac 备份来补齐设定，保留 Pad 的进度与书签。

## 界面与平台边界

手机使用底部面板，长按钮纵向排列；低频参数、设定说明与费用细节按需展开。中、英、日界面同步，日语试读支持假名注音。

Mac 当前仍为 v0.11.11；本次对应的是试读、连载生成与阅读任务。Android 暂不包含 Mac 的写作、评审、科学题库及选级对照等既有模块。两端数据不自动同步，Android 阅读备份也不能作为 Mac 全库备份导入。

## 验证与限制

- 8 项 Android 单元测试、三组浏览器回归通过，覆盖旧备份、连载信息、重导入不丢章节、原始要求重新试读、后台连续生成、部分保存、失败续接、停止后的晚到结果、重启恢复和 320–1280 宽度布局。Mac 62 项单元测试及类型检查通过，Mac 运行源码未改动。
- 最终 APK 在 Android 16 ARM64 专用平板模拟器通过旧版 0.2.1 覆盖升级，验收系统文件导入／导出、实际滑动、翻页动画正文、书签、主题、系统返回、横竖屏、密钥库、同签名重装与数据保留。
- 最终 APK 的独立原生连载回归通过：原始要求重新试读、原生密钥会话、顺序生成、摘要与记忆衔接、失败后只补剩余章节、停止后忽略晚到结果，以及进程重启后的续接；已有书库保留。
- 所有生成测试使用受控模型响应，没有真实付费 Gemini API 调用，不代表文学质量或生成速度验收。

这是本机调试签名的预览包，尚未上架，没有自动更新。实体 Pad、Android 10 最低系统和其他厂商 WebView 尚未实机验收。安装前建议导出备份；不要先卸载旧应用，以免丢失本机数据。正式签名变更可能需要备份后重装。
