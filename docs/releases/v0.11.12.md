# Leaflight v0.11.12

2026-10-30 · Apple Silicon macOS · 手动安装 DMG

## 共享书池（Community Story Pool · 免 API Key 借阅与分享）

在左侧导航栏或书架顶部新增「共享书池」，让尚未配置 Gemini API Key 的读者可以直接阅读英日分级故事，也让已经生成满意小说的读者一键脱敏分享到公共书池。

- **内置双语分级种子小说**：预置 4 部完整英日分级故事（含英语 CEFR A2–B2 与日语 JLPT N4 `<ruby>` 振假名注音），首次打开无需联网或配置 Key 即可按语言与等级筛选、展开「开篇试读」，一键加入本地书架离线阅读。
- **从 GitHub 同步最新**：点击「从 GitHub 同步最新」可直接从本仓库 `community-pool/index.json` 及开放的社区投稿 Issue 拉取最新共享作品，经本地结构与长度校验后缓存在本地数据库中；同时支持导入单篇 `.leaflight-story.json` 分享文件。
- **一键脱敏分享到公共书池**：在书架卡片或阅读器顶部点击「分享 / 分享到书池」，系统自动剥离阅读进度、个人书签、难度反馈与本地任务 ID，并提供三种分享方式：
  1. **免 Token · 浏览器一键投稿（推荐）**：自动复制完整作品 Markdown 与 `leaflight-story` 代码块到剪贴板并打开 GitHub Issue 页面，粘贴提交后由 GitHub Actions 自动校验并归档入池；
  2. **客户端直传至 GitHub 书池**：可选配置 GitHub Personal Access Token（经 Electron `safeStorage` 加密保存，不写入导出备份）直接从客户端发布；
  3. **导出分享文件 (`.leaflight-story.json`)**：保存为独立 JSON 文件，可供 Mac 或 Android 端直接导入。
