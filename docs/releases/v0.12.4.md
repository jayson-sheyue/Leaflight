# Leaflight v0.12.4 — Text selection vs. page-turn gesture separation

- Restored native press-and-drag text selection in paged reading mode on Mac, Windows, and the web preview: holding the left mouse button and dragging, pressing and dragging on a trackpad (including three-finger drag), or long-pressing and dragging on a touchscreen now selects strings for copy/paste without turning the page or scrubbing adjacent CSS columns.
- Added a localized right-click context menu (`Copy` / `Cut` / `Paste` / `Select All`) in the desktop app alongside `Cmd+C` / `Ctrl+C`, kept `Shift + Arrow` free for extending text selection, and prevented mouse drag selection in full-window mode from toggling the floating `Inbox / Exit` bar.
- Paged page turns trigger cleanly on a quick horizontal touch swipe, a two-finger horizontal trackpad scroll (including right after selecting text or while hovering over the bottom bar), the bottom `Previous / Next` buttons, and unmodified `ArrowLeft / ArrowRight / PageUp / PageDown` keys.
- Android Reader 0.3.0-preview.9 receives the matching long-press selection vs. quick-swipe page-turn update.
- iPhone and iPad use the [web preview](https://jayson-sheyue.github.io/Leaflight/). There is no iOS installer.
