# Leaflight v0.11.10

2026-10-30 · Apple Silicon macOS · 手动安装 DMG

## 选级试读的用途说明

「同情节难度对照」用于创作前的一次短场景试读，帮助用户凭阅读感受选择目标难度；可按需重新体验。

- 对照窗口明确标注这是辅助选级的小样，不生成整部小说的两个难度版本，不认证用户语言等级，也不自动修改创作设置。
- 按钮改为「生成选级试读」，选择框改为「试读等级 A / B」。每次体验发起一次 Gemini 请求，可能产生 API 费用；最近一次结果可以离线回看。
- 用户试读后需返回创作设置手动选择小说难度。
- README 明确入口：左侧「创作新故事」→「篇幅与更多选项 · 可保持默认」→「同情节难度对照」。演示截图标注自动测试模拟文本，不作为真实生成质量的证明。

此前已经具备短场景生成逻辑，本版本澄清其产品用途与交互说明。
