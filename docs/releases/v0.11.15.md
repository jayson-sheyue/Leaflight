# Leaflight v0.11.15 — Gemini 密钥来源兼容

- 系统设置新增 AI Studio／Vertex AI Express 来源选择；旧式 Key 和带点授权密钥均可保存，来源不依赖密钥前缀判断。
- Express 请求固定使用 Google 全局 `v1beta1` 端点，AI Studio 保留 `v1beta`；两者均通过请求头传密钥，保留 JSON schema 和显式 user 角色。
- Mac 的排队／连续生成持有提交时的密钥与服务快照；Android 原生会话持有开始时快照。切换设置不改变正在执行的任务，不自动跨服务重试。
- Android Reader 0.3.0-preview.4 同步设置、原生路由与密钥保存；模型权限、地区和配额仍由所选平台决定。

见 [API 配置与发送范围](../api-references.md)。默认继续使用 AI Studio；Vertex Express Key 请在设置中选择对应来源。文本或某个模型可用不代表所有模型、TTS 或免费额度均可用。

## 验证与限制

76 项 Mac／共享单元测试、10 项 Android 单元检查、Java 网关契约与两端构建已执行；桌面受控请求验证两种来源、密钥遮罩、重启及连续生成设置快照。最终安装包、升级和原生 APK 的具体结果见 Release 附件。

没有使用真实 AQ 密钥调用 Google，不能据此声称账号上的 Express 模型已通过线上验收。Mac 仍为 ad-hoc 签名，无 Developer ID／Apple 公证；Android 为同签名调试预览包，实体 Pad 与最低系统版本未实机验证。仍需从 Release 手动更新，没有 OTA。
