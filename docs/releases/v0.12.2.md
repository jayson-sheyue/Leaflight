# Leaflight v0.12.2 — Drag and trackpad page turns

- In paged mode on Mac, Windows, and the web preview, pressing and dragging the text, or scrolling horizontally with a trackpad, turns one page and plays the selected effect. The text stays still during the gesture. Buttons and arrow keys still turn pages. Reduced motion still turns the page without the effect.
- One continuous trackpad gesture turns only one page. A later gesture, after it has settled, turns the next page.
- Download this release instead of v0.12.1 when you want that gesture in the installed app. The v0.12.1 packages do not turn pages from a drag or a two-finger trackpad swipe.
- Android Reader 0.3.0-preview.7 already turns a page from a finger swipe and is unchanged in this release.
- iPhone and iPad use the [web preview](https://jayson-sheyue.github.io/Leaflight/). There is no iOS installer.
